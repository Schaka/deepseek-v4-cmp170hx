## Infra changes on this branch

- `launch/rebuild-image.sh`: points at `12810046c` via plain shallow clone (not tarball
  recovery), separate `$HOME/build-12810046c` work dir so it never collides with `main`'s
  `~/build` on the workstation. Skips `0001` and `0009` in the patch-staging loop. Also fixes
  a real bug found while working on this: the syntax-check loop used to pipe `patch`'s output
  through `grep '^patching file'`, which silently discarded any FAILED-hunk diagnostic text —
  a real patch failure aborted the whole script via `set -e`/pipefail with **zero error
  output**. Now captures full output and prints it on failure. Worth backporting to `main`'s
  copy of this script independent of whether this rebase ever lands.
- `patches/needs-rework/0006-logits-row-chunk.patch` — moved out of `patches/` so the glob in
  `rebuild-image.sh` doesn't pick it up while it's broken; not deleted.
